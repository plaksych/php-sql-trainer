# Симулятор подготовки к тестированию (Git, PHP, Docker)

Этот тренажер разработан специально для подготовки к тестированию по технологиям разработки веб-приложений (на платформе hh.ru). Он поможет вам быстро вспомнить и структурировать ключевые теоретические и практические аспекты.

## 🚀 Как запустить симулятор

Поскольку проект разработан как Single-Page Application (SPA) на чистом HTML, CSS и JavaScript, для его работы не требуется установка серверов или баз данных.

### Вариант 1: Запуск напрямую через браузер (Самый простой)
1. Откройте директорию проекта.
2. Дважды кликните по файлу `index.html` или перетащите его в окно любого современного браузера (Google Chrome, Firefox, Safari, Edge).
3. Готово! Симулятор работает локально в вашем браузере.

### Вариант 2: Запуск с помощью локального HTTP-сервера (Для корректного кеширования)
Если у вас установлен Node.js или Python, вы можете запустить простой сервер:
- **Node.js (npx)**:
  Выполните команду в терминале в папке проекта:
  ```bash
  npx serve .
  ```
  и откройте ссылку `http://localhost:3000` (или ту, которую выдаст консоль).
- **Python**:
  Выполните команду:
  ```bash
  python -m http.server 8000
  ```
  и откройте `http://localhost:8000` в браузере.

1. **Интерактивные тесты (Дашборд)**:
   - **Git (Теория)** — 12 вопросов (ветвление, слияние, отмена коммитов, сброс изменений, git stash, revert).
   - **PHP (Теория)** — 12 вопросов (типы данных, сравнение `==` и `===`, области видимости, интерфейсы, абстрактные классы, declare(strict_types)).
   - **Docker (Теория)** — 12 вопросов (образы и контейнеры, Dockerfile инструкции, Docker Compose, volumes, порты).

2. **Практика PHP (Песочница)**:
   - 5 классических задач, которые часто встречаются на тестировании (фильтрация массивов, форматирование строк с ФИО, расчет среднего балла в ассоциативном массиве, безопасная выборка по ключу, реализация наследования ООП класса).

3. **Флеш-карточки (Карточки)**:
   - 12 интерактивных двусторонних карточек для быстрого заучивания и самопроверки ключевых терминов и различий (например, `revert` против `reset`, `Image` против `Container`, `isset` против `empty`). Кликните на карточку, чтобы перевернуть её.

4. **Шпаргалки (Шпаргалки)**:
   - Полноценная база данных основных консольных команд Git, Docker, инструкций Dockerfile и встроенных функций PHP для быстрой работы с массивами и строками.
   - Встроенный **мгновенный поиск** по шпаргалкам по мере ввода и кнопка копирования команд в один клик.

## 💡 Советы по подготовке

1. **Разберитесь с Git Staging Area**: Поймите, что такое индекс (staging area) и чем отличаются `git reset --soft` (файлы возвращаются в индекс) и `git reset --hard` (изменения полностью стираются).
2. **Изучите Dockerfile и Docker Compose**: Обратите особое внимание на разницу между `RUN` (сборка образа) и `CMD` (запуск контейнера).
3. **Особые правила PHP**:
   - Строка `'0'` в PHP возвращает `true` при проверке функцией `empty()`.
   - Оператор объединения строк — это точка `.` (а не `+`).
   - `protected` виден в классах-наследниках, а `private` — нет.
